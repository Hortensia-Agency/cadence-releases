Cadence

Les exports PRONOTE, convertis pour HRA.

Cadence surveille votre dossier d'exports et écrit chaque emploi du temps au format CSV SOPRA, sans intervention.

Installer

Windows

  1. Décompressez Cadence-windows.zip, par exemple dans C:\Program Files. Vous obtenez un dossier Cadence.
  2. Lancez Cadence.exe dans ce dossier. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis Exécuter quand même.
  3. Saisissez votre clé de licence. Une connexion internet est nécessaire pour l'activation.

macOS

  1. Ouvrez Cadence.dmg et glissez Cadence dans le dossier Applications.
  2. Au premier lancement, faites un clic droit sur Cadence, puis Ouvrir. macOS demande une confirmation la première fois seulement.
  3. Saisissez votre clé de licence. Une connexion internet est nécessaire pour l'activation.
